# SwiftTrack Recovery website

1. **Add your email:** open `js/main.js` and replace `your-email@example.com` (the only place to change it).
2. **Upload to GitHub:** create a repo named `swifttrackrecovery.github.io` (needs a GitHub account named `swifttrackrecovery`; otherwise use any repo name), then upload everything in this folder.
3. **Go live:** repo Settings > Pages > Deploy from branch > `main` > `/ (root)` > Save. Your site appears in a minute or two.
4. **Google:** add the site at search.google.com/search-console and submit `sitemap.xml`. If your address differs from the one in `sitemap.xml` and `robots.txt`, edit those two files.
5. **Later:** to use a .com domain, add it under Settings > Pages > Custom domain.

The contact form opens the visitor's email app with the message filled in. No social media links are included.
